# ClassIng 使用教程（写给完全不懂技术的老师和同学）

> 本教程面向**零基础用户**：不需要懂编程，跟着步骤一步一步做即可。
> 看不懂的词，文中都会用括号解释；每一步都标注了「点哪里、看到什么、下一步是什么」。

---

## 这个插件是做什么的？

ClassIng 是一个装在 **ClassIsland**（一款常见的教室课表大屏软件）里的**插件**（可以理解为给软件加装的一个"功能包"）。装好之后，它能做三件事：

1. **自动盯群**：班级 QQ 群里老师或课代表发的作业、通知，它会自动记录下来；
2. **自动下载文件**：群里发的文件（试卷、练习册图片等）会自动下载，按学科、日期分好文件夹存好；
3. **上屏提醒**：在教室大屏上用两个小窗口（悬浮窗）展示最新通知和作业列表，谁看了点一下"已读"就行。

> **关于安全，请放心**：本插件使用的是 **QQ 官方机器人开放平台**（腾讯官方提供的正规机器人通道，网址 q.qq.com）。它走的是腾讯官方渠道，**不存在封 QQ 号的风险**——这是它和网上各种"外挂式"机器人最大的区别。

### 使用前必须知道的三件事

| 事项 | 说明 |
| --- | --- |
| 群文件面板里的文件收不到 | 如果有人把文件直接上传到 QQ 群的"群文件"面板（就是群聊右上角那个"文件"入口里），插件**收不到**。正确做法：**把文件像发图片一样直接发到聊天框里**。 |
| 拿不到真实 QQ 号 | 出于腾讯官方的隐私规则，插件只能看到每个成员的一串随机代号（叫 OpenID，可以理解为"化名"），**看不到真实 QQ 号码**。这不影响正常使用。 |
| 补不到历史消息 | 插件启用**之前**群里已经发过的消息，它收不到（腾讯官方不提供"翻旧消息"的接口）。启用后开始正常记录。 |

## 一、准备工作

开始安装前，请准备好以下东西。整个过程大约需要 30 分钟（大部分时间在等审核）。

### 步骤 1：准备一台电脑和一个 QQ 号

- 一台安装了 Windows 系统的电脑（就是教室里跑 ClassIsland 课表的那台电脑）；
- 老师本人的 QQ 号，并且**老师是班级群的群主或管理员**（机器人进群必须由群主/管理员操作，别人拉不进去）。

### 步骤 2：注册 QQ 官方机器人（在 q.qq.com）

这一步是在腾讯的机器人管理网站上"给班级申请一个官方机器人账号"。

1. 打开浏览器，访问 **q.qq.com**（QQ 机器人开放平台官网）。
2. 点击页面上的「注册」或「登录」，用老师的 QQ 号扫码登录。
3. 登录后，网站会要求选择主体类型，选择「**个人开发者**」即可（班级使用不需要企业认证）。
4. 按网站提示完成**实名认证**（需要身份证信息+人脸识别，这是腾讯的正规流程，不是诈骗）。
5. 实名通过后，回到控制台首页，点击「**创建机器人**」。
6. 填写机器人资料：
   - 名称：例如「三年二班小助手」；
   - 头像：随便选一张图片；
   - 简介/功能描述：写「班级作业与通知自动整理」即可。
7. 提交后等待平台**审核**（通常几分钟到几天不等，个人自用机器人一般很快）。
   - 【截图位：q.qq.com 创建机器人表单页面】
8. 审核通过后，进入机器人的「**开发设置**」页面，你会看到两串字符：
   - **AppID（机器人 ID）**：一串数字，公开的，不用保密；
   - **AppSecret（机器人密钥）**：一串字母数字，**相当于机器人的"密码"**。
   - 【截图位：开发设置页面中 AppID 与 AppSecret 的位置】
9. 点击 AppSecret 旁边的「复制」按钮，**先把这两串字符分别粘贴保存到记事本里**（后面安装要用）。

> ⚠️ **安全提示（非常重要）**：AppSecret 就是机器人的密码，**不要发给任何人**，不要发到班级群里，不要发朋友圈。只有你自己（和帮装插件的老师）需要它。如果怀疑泄露了，回到 q.qq.com 的开发设置页面点击「重置」即可换一个新的。

### 步骤 3：把机器人拉进班级群（群主/管理员操作）

1. 打开 QQ，进入班级群。
2. 点击右上角的「群聊设置」（三条横线或齿轮图标）。
3. 找到「**群机器人**」→ 点击「**添加机器人**」。
4. 在列表里搜索你在步骤 2 创建的机器人名字，点击「添加」。
5. 回到群聊，看到机器人出现在成员列表里，就成功了。
   - 【截图位：QQ 群聊设置 → 群机器人 → 添加机器人界面】

### 步骤 4：打开「接收所有消息」开关（关键！）

这一步决定机器人能不能"不 @它 也能看到群里每条消息"。**不开这个开关，插件基本收不到消息**。

1. 回到 **q.qq.com** 的机器人管理页面。
2. 找到「**功能配置**」或「消息推送」相关的页面。
3. 找到「**接收所有消息**」（也叫"群消息全量模式"）的开关，**打开它**。
   - 【截图位：q.qq.com 管理页中「接收所有消息」开关位置】
4. 打开后页面可能提示需要再次确认或重新审核，按提示操作即可。

准备工作完成！你现在手里应该有：**AppID、AppSecret（存在记事本里）、一个已进群的机器人（开关已打开）**。

## 二、安装与首次启动

> 以下步骤假设你拿到的是一个**整合包/安装包**（里面已经包含 ClassIsland 主程序和 ClassIng 插件，双击安装即可，不需要懂任何技术）。

### 步骤 1：安装

1. 找到下载好的安装包文件（通常在「下载」文件夹里，文件名类似 `ClassIsland-Setup-xxx.exe`）。
2. 双击运行。如果 Windows 弹出蓝色警告框，点击「更多信息」→「仍要运行」（这是因为软件没有花钱买微软的签名证书，正常现象）。
3. 按安装向导一路点「下一步」→「安装」→「完成」。
   - 【截图位：安装向导界面】

### 步骤 2：首次启动 ClassIsland

1. 双击桌面上的 ClassIsland 图标启动程序。
2. 第一次启动会出现 ClassIsland 自己的引导（设置学校、课表等），按它自己的提示完成即可——这部分与插件无关。
3. 启动完成后，ClassIsland 会自动加载 ClassIng 插件，屏幕上（或屏幕边缘）会出现**两个小窗口**：
   - **通知悬浮窗**：显示最新通知，带「已读」按钮；
   - **作业悬浮窗**：按学科（语文/数学/英语……）分组显示作业。
   - 【截图位：教室大屏上两个悬浮窗的样子】

### 步骤 3：打开 ClassIng 的设置页，填入机器人信息

1. 在 ClassIsland 主界面点击「设置」（齿轮图标）。
2. 在设置窗口左侧列表找到「**ClassIng**」分组（或名为「QQ 群消息」的页面），点击进入。
   - 【截图位：设置窗口中 ClassIng 设置页入口】
3. 在「**连接设置**」里：
   - **AppID**：粘贴你保存在记事本里的 AppID；
   - **AppSecret**：粘贴 AppSecret（界面上会显示成 ●●●● 隐藏状态，这是正常的，它已被加密保存）；
   - 【截图位：连接设置中 AppID/AppSecret 输入框】
4. 点击页面下方的「**保存**」按钮（有的版本叫「应用」）。
5. 观察页面顶部的**连接状态指示**：显示「已连接」（通常带绿色圆点）就说明成功了。
   - 【截图位：连接状态显示「已连接」】
6. 如果显示「连接中」超过 1 分钟或「已断开」，跳到本文第五章「常见问题排查」第 5 条。

### 步骤 4：配置群白名单（告诉插件只听哪个群）

「白名单」就是"允许名单"——只接收列在名单里的群的消息，防止听到无关的群。

1. 让任何一位同学**在班级群里随便发一条消息**（随便说句话即可）。
2. 打开 ClassIng 设置里的「**排错面板**」（或叫「诊断」页面），在「最近消息」里找到刚才那条消息，记下它显示的**群标识（群 OpenID，一串字母数字）**。
   - 【截图位：排错面板中最近消息与群 OpenID 的展示位置】
3. 复制这串 OpenID，粘贴到「连接设置 → 群白名单」的列表里，保存。
4. 配置好白名单后，插件就只处理这个班级群的消息了。

> 推荐配置白名单。如果留空，插件会接收机器人所在的**所有**群的消息，一般不建议。

### 步骤 5：发条消息测试一下

1. 在班级群里让一个人发送：「数学作业：课本第 10 页练习一」。
2. 几秒内，作业悬浮窗应出现一条「数学」分组的作业；通知类消息（含"通知"等字样）则出现在通知悬浮窗。
3. 看到了 → 恭喜，安装完成！没看到 → 见第五章第 1 条。

## 三、日常使用

装好之后，日常只有三个动作：**发消息 → 看悬浮窗 → 点已读**。详细说明如下。

### 3.1 老师/课代表：怎么发才有效

- **直接在群聊天框里发**文字、图片或文件即可（就像平时发消息一样），不需要 @机器人。
- 发**文件**（试卷、课件等）时，请点聊天框的「文件/图片」按钮**发送到聊天里**；不要传到"群文件面板"（那个收不到）。
- 想让某条消息被当作"作业"，消息里带上「作业」「练习」「提交」这类词；想当作"通知"，带上「通知」「注意」「提醒」这类词（这些词可以在设置里改，见 4.2）。
- 带不上关键词也没关系：识别不准的内容会进入「待确认列表」，人工点一下就能归类（见 3.4）。

### 3.2 学生：看悬浮窗、点已读

1. 教室大屏上，通知悬浮窗会显示最新一条通知，作业悬浮窗按学科分组列出今天的作业。
2. 看完/抄完之后，点悬浮窗上的「**已读**」按钮（作业悬浮窗里每条作业也可以单独标记完成）。
3. 标记已读的内容会收起来；**已读状态会被记住，教室电脑重启后也不会"复活"**。
4. 悬浮窗可以**拖动**：按住窗口边缘空白处拖到不挡黑板的位置。位置会被记住。

### 3.3 发现学科标错了？手动改一下

如果「英语作业」被标成了「未分类」或别的学科：

1. 在作业悬浮窗里找到那条作业，点击它（或点击旁边的「修正学科」小按钮）。
2. 在弹出的列表里选择正确的学科，比如「英语」。列表里始终有 **语文、数学、英语、物理、化学、生物、其他** 七项可选，不受任何设置影响。
   - 【截图位：作业悬浮窗中修正学科的弹窗】
3. 改完立即生效，文件归档位置也会跟着更新（详见 4.4 的按学科归档）。
4. **改一次，记住这个人**：把某个同学发的「未分类」作业改到某学科后，这个人之前发的所有作业会自动改成该学科；以后这个人再发作业，也会直接归到该学科（永久记住，重启不丢）。想换学科时再手动改一次即可覆盖。

### 3.4 「待确认」列表：拿不准的作业由人来定

机器有时拿不准一条消息是哪个学科的（尤其消息里没带任何学科词时）。这种消息不会丢失，而是进入「**待确认**」列表：

1. 打开设置里的「待确认」页面（或在作业悬浮窗上出现"有待确认内容"的提示）。
   - 【截图位：待确认队列页面】
2. 每条待确认内容会显示消息原文和它的"猜测"，你点选一个正确学科即可。
3. 确认后该条自动进入对应学科的作业列表。

### 3.5 下载的文件在哪找？

- 群里发来的文件会自动下载到「**下载文件**」文件夹里，按 `学科\日期` 分子文件夹存放，例如：`下载文件\数学\2026-09-04\期中试卷.pdf`。
- 这个文件夹的默认位置在 ClassIsland 数据目录下；也可以在设置里改到任何位置（如 U 盘、共享盘），见 4.4。
- 重复发同一个文件只会保留一份（插件按文件内容自动去重）。

## 四、设置详解（五组）

打开 ClassIsland 设置 → ClassIng 页面，共有五组设置。**大多数选项保持默认即可正常使用**，下面逐项说明并给出推荐值。

> 【截图位：ClassIng 设置页五组设置的全览】

### 4.1 连接设置（插件怎么连上 QQ 机器人）

| 设置项 | 作用 | 推荐值 |
| --- | --- | --- |
| AppID | 机器人的"身份证号"（q.qq.com 获取） | 填你自己的，必填 |
| AppSecret | 机器人的"密码"（加密保存） | 填你自己的，必填；**不要外泄** |
| API 根地址 / Token 服务地址 | 腾讯官方接口地址 | **保持默认**，不要改 |
| 群白名单 | 只接收名单内群的消息（填群 OpenID） | 填上班级群的 OpenID（获取方法见二·步骤 4） |
| 断线重连参数（初始延迟/倍数/上限） | 网断了以后自动重连的节奏 | **保持默认**（2 秒起、每次翻倍、最长 5 分钟） |
| 历史消息回溯天数 | 想补拉启用前的旧消息 | **改不了**：腾讯官方不提供，固定为 0，属于正常现象 |

### 4.2 分类设置（怎么区分"通知"和"作业"、怎么认学科）

| 设置项 | 作用 | 推荐值 |
| --- | --- | --- |
| 通知关键词 | 消息含这些词 → 判定为通知 | 默认「通知/注意/提醒/广播」，可按班级习惯增删 |
| 作业关键词 | 消息含这些词 → 判定为作业 | 默认「作业/练习/提交/完成」 |
| 学科关键词表（subjects.json） | "数学、几何、方程"这类词对应哪个学科 | 在设置页编辑即可；改完立即生效，无需重启 |
| AI 识别开关 | 关键词认不出时，用 AI 帮忙认学科 | 保持开启 |
| 本地模型优先 | 优先用装在电脑上的小模型识别（不花钱、断网可用） | 保持开启 |
| 本地模型路径 | 小模型文件的位置 | 保持默认 |
| 云端接口地址 / API 密钥 / 模型名 | 接一个外部 AI 服务兜底（可选，需另外购买/注册） | **零基础用户可不填**：不填时自动只用关键词+人工确认，功能不受影响 |
| 云端每日调用上限 | 防止云端 AI 花费失控 | 保持默认（200 次/天） |
| 置信度阈值 | 机器"把握程度"低于该值时转人工确认 | 保持默认（0.7）；嫌人工确认太多可调低到 0.6 |
| 人工确认队列开关 | 拿不准的先攒着等人确认 | 保持开启（关了会把拿不准的直接标"未分类"） |

### 4.3 悬浮窗设置（悬浮窗的样子、位置与联动）

通知窗、作业窗、学科文件窗和学科圆圈栏各有一套相同的项目：

| 设置项 | 作用 | 推荐值 |
| --- | --- | --- |
| 位置 X / Y | 窗口在屏幕上的坐标 | 默认即可；拖动窗口也会自动记住位置 |
| 宽度 / 高度 | 窗口大小 | 默认 320×480，适合教室大屏侧边 |
| 不透明度 | 窗口透明程度（0.1 很透，1.0 全实） | 默认 0.92，基本不挡背景又不突兀 |
| 字号 | 文字大小 | 教室后排要看清的话建议 16–20 |
| 置顶 | 开：悬浮窗浮在所有窗口之上；关：悬浮窗钉在桌面层最底，所有窗口都会遮挡它。两种模式下按 Win+D 显示桌面、鼠标移到右下角，悬浮窗都不会消失 | 保持关闭（钉在桌面层） |
| 固定 | 禁用拖拽缩放、点击不抢焦点；关闭后可拖动调整位置大小（层级由「置顶」决定，与本开关无关） | 保持开启 |
| 鼠标穿透 | 鼠标点击直接穿过悬浮窗落到下方窗口（想操作悬浮窗需先到设置里关掉穿透） | 按需，默认关闭 |
| 显示 | 窗口开关 | 保持开启；不需要时可在设置里关掉 |
| 随宿主启动 | ClassIsland 一开机两个窗就出现 | 保持开启 |

> 悬浮窗被拖到屏幕外找不到了？见第五章第 2 条，有「一键复位」。

#### 学科圆圈启动器与学科文件悬浮窗

屏幕边上有一排（或一列）**学科圆圈**：点哪个圆圈，就会弹出（或切换到）该学科已归档文件的悬浮窗。上课时老师想翻某个学科的作业、卷子，点一下就有，不用去文件夹里翻。相关设置都在 设置 → 悬浮窗设置：

| 设置项 | 作用 | 推荐值 |
| --- | --- | --- |
| 圆圈排列方向 | 圆圈横着排还是竖着排 | 圆圈栏放在屏幕侧边就选「纵向排列」（默认）；横向排列时记得把圆圈栏宽度调大、高度调小，反之亦然 |
| 视图模式 | 文件悬浮窗里文件的摆法：大图标（文件名在图标下方，流式排列）或详细列表（小图标在左、完整文件名在右） | 大图标（默认）；文件多、名字长选「详细列表」，该选择会记住，重启不丢 |
| 学科顺序 | 圆圈的排列顺序 | 在圆圈上点右键选「上移 / 下移」即可；设置页的编辑框也可改（每行一个学科名，没填的按固定顺序排在后面） |
| 上课时自动弹出对应学科文件悬浮窗 | 进入上课状态时自动弹出（或切换到）当前学科对应的文件悬浮窗，下课、放学自动收起 | 建议开启（需 ClassIsland 课表正常才有意义） |
| 显示圆圈栏 / 显示悬浮窗（学科文件窗） | 两个窗口的开关 | 圆圈栏保持开启；学科文件窗保持默认（默认隐藏，由圆圈点击唤出） |

注意两点：

- 圆圈栏展示「固定七学科 + 文件归档里出现过的学科」；某学科还没有归档文件时，点它只会打开一个空列表。
- **上课自动弹出按课表匹配**：以 ClassIsland 课表的当前科目名，去已归档的学科文件夹里找对应内容。当前没有课、课间休息、课表里查不到当前科目，或该科目还没有归档文件时，都**不会弹窗**（这是正常现象，不是坏了）。

### 4.4 文件设置（下载与归档）

| 设置项 | 作用 | 推荐值 |
| --- | --- | --- |
| 下载根目录 | 文件存哪里 | 默认在插件数据目录下；教室电脑建议改到一个空间充足的盘，如 `D:\班级文件` |
| 按学科建目录 | 自动分 `数学\、语文\…` 文件夹 | 保持开启 |
| 重复文件去重 | 相同内容只存一份 | 保持开启 |
| 磁盘占用上限 | 下载文件总共最多占多少 MB | 默认 2048（2 GB）；空间紧张的电脑可调小 |
| 清理策略 | 到达上限怎么办：0=停止收新文件并提示；1=自动删最旧的文件 | 长期无人管的电脑选 1；想人工控制选 0 |
| 同时下载数 | 同时下载几个文件 | 保持默认（2） |
| 下载限速 | 限制下载速度，避免占满网速 | 默认 0（不限）即可 |
| 单文件大小上限 | 超大的文件拒收并提示 | 默认 512 MB |
| 文件名最大长度 | 防止超长文件名出错 | 保持默认 |

### 4.5 维护设置（日志与重试）

| 设置项 | 作用 | 推荐值 |
| --- | --- | --- |
| 日志级别 | 记录多详细（Info=正常，Debug=更详细，供排查问题） | 平时 Info；报障时临时改 Debug |
| 重试队列开关 | 下载失败/写入失败时自动重试 | 保持开启 |
| 重试次数上限 | 重试几次后放弃（放弃的可在排错面板手动重放） | 保持默认（5 次） |

## 五、常见问题排查

### 问题 1：群里发了消息，悬浮窗没反应（收不到消息）

按顺序检查，**最常见的是第 1 条**：

1. **「接收所有消息」开关没开**：登录 q.qq.com → 你的机器人 → 功能配置，确认「接收所有消息」已打开（见一·步骤 4）。这是最常见的坑。
2. **机器人被移出了群**：在 QQ 群成员列表里确认机器人还在；不在就重新「添加机器人」。
3. **群白名单没配或填错**：设置 → 连接设置 → 群白名单，确认里面填的是本班群的 OpenID（获取方法见二·步骤 4）。不确定就先暂时清空白名单测试（清空=接收所有群），收到消息后再填回正确值。
4. **连接状态不是"已连接"**：看设置页顶部状态；不是绿色就先做问题 5 的检查。
5. **消息是启用插件之前发的**：旧消息收不到（见开头"三件事"），重新发一遍即可。

### 问题 2：悬浮窗不见了（找不到了）

1. **被拖出屏幕了**：打开设置 → 悬浮窗设置，点击「**一键复位**」按钮，窗口会回到默认位置（屏幕左上角附近）。
2. **窗口被关闭/隐藏了**：在同一页面确认「显示」开关是打开的。
3. **被其他窗口挡住了**：这是正常现象——悬浮窗默认在最底层，任何窗口都会遮挡它；把遮挡的窗口移开或最小化即可看到悬浮窗。想让悬浮窗永远显示在最上面，可在设置 → 悬浮窗设置里打开「置顶」。
4. **点了悬浮窗没反应**：检查是否开了「鼠标穿透」——穿透模式下点击会直接穿过悬浮窗，需到设置里关掉再操作。
5. 都不行就重启一次 ClassIsland（右键任务栏托盘图标 → 退出，再双击桌面图标启动）。

### 问题 3：作业学科识别错了 / 全显示"未分类"

1. **先手动改**：在作业悬浮窗点该条作业 → 选正确学科（见 3.3）。
2. **补充关键词表**：设置 → 分类设置 → 学科关键词表，把班上常用的说法加进去。例如学生爱说"卷子"，就给"数学"学科加上关键词「卷子」「口算」。改完立即生效。
3. **消息里完全没有学科词**：这类会进"待确认"列表，人工确认即可（见 3.4）；也可以提醒发消息的同学带上学科名（如"英语作业：……"）。
4. 如果装了云端 AI 但识别仍差：检查 4.2 中云端三项是否填写正确、每日额度是否用完。

### 问题 4：文件没被下载归档

1. **最常见原因：文件发到了"群文件面板"**。群文件面板（群聊右上角"文件"入口）里直接上传的文件，插件收不到。请同学**把文件直接发到聊天框里**（跟发图片一样）。建议在群里约定："交文件请发聊天里"。
2. **文件太大**：超过单文件大小上限（默认 512 MB）会被拒收并提示，可在 4.4 里调大或让同学压缩后发。
3. **磁盘满了**：到达磁盘占用上限后按清理策略处理（见问题 6）。
4. **下载失败在重试**：文件可能显示"处理中"，稍等；反复失败可打开排错面板查看失败原因并手动重放。

### 问题 5：连接不上 / 提示 Token 失效

"Token"可以理解为插件用 AppSecret 换来的一张"临时通行证"，会定期自动续期。连不上时按顺序检查：

1. **AppID / AppSecret 填错**：回 q.qq.com 的开发设置页重新核对、重新复制粘贴一遍（最容易多复制一个空格，注意删掉）。填错或重置过 Secret 都会导致连不上。
2. **AppSecret 最近被重置过**：如果有人在 q.qq.com 上点了「重置」，旧密码立即作废，必须把**新** Secret 填回插件。
3. **教室电脑断网了**：打开浏览器随便开个网页试试；恢复网络后插件会自动重连（最长等 5 分钟），着急可在排错面板点「手动重连」。
4. **腾讯服务临时维护**：极少见，等几分钟再看状态。

### 问题 6：提示磁盘空间不足

1. 这是保护机制：下载文件总量到达了 4.4 里的「磁盘占用上限」。
2. 想全自动：把「清理策略」改为 1（自动清理最旧的文件），插件会删旧文件腾地方。
3. 想人工控制：保持策略 0，然后手动清理「下载文件」文件夹里不需要的旧文件（建议先备份到期末）。
4. 也可以把「下载根目录」改到剩余空间更大的盘。

### 问题 7：上课了，学科文件悬浮窗没自动弹出

1. **开关没开**：设置 → 悬浮窗设置 → 「圆圈栏排列与文件悬浮窗联动」→「上课时自动弹出对应学科文件悬浮窗」。
2. **课表里查不到当前课**：课间休息、没有排课、或 ClassIsland 课表本身没数据时不会弹（见 4.3 的说明）。
3. **该学科还没有归档文件**：当前科目在归档目录里找不到对应学科文件夹时不弹；先让同学把文件发到群里归档一次。
4. **弹的是别的学科**：当前科目名与归档学科是「包含」关系时也能匹配（如科目「数学(提高班)」能匹配归档的「数学」）；如果名字完全对不上，检查文件设置里的学科目录名。

### 问题 8：其他奇怪问题

1. 先重启 ClassIsland（能解决大部分偶发问题）。
2. 打开排错面板，把日志级别临时改为 Debug，复现问题后把日志提供给会处理的人。
3. 设置改乱了想重来：设置里有「恢复默认」和「导出/导入」功能——改乱前可以先「导出」一份备份。

## 六、一页速查（贴在讲台边的那种）

### 日常三步

1. **发消息**：老师/课代表在班级群里直接发作业、通知、文件（文件发到聊天里，别放群文件面板）。
2. **看悬浮窗**：教室大屏上，作业按学科分组、通知显示最新一条。
3. **点已读**：看完点「已读」，完成作业就标记完成。

### 出问题时

| 现象 | 第一反应 |
| --- | --- |
| 悬浮窗没动静 | 查 q.qq.com 的「接收所有消息」开关 → 机器人是否还在群里 → 白名单 |
| 悬浮窗不见了 | 设置页点「一键复位」 |
| 学科标错 | 点作业改学科；往关键词表加词 |
| 上课没自动弹文件 | 查联动开关；查课表有没有当前课；查该学科有没有归档文件 |
| 文件没下载 | 文件要发聊天里；查文件大小和磁盘上限 |
| 连不上 | 重填 AppSecret；查网络 |

### 安全两条

- **AppSecret 不要发给任何人**，不进群聊、不进截图。泄露就去 q.qq.com 重置。
- 插件走 QQ 官方渠道，**不碰 QQ 账号本身，无封号风险**，放心用。
