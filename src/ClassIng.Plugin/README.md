# CyberTechRep 课堂信息分发

ClassIsland 插件：QQ 群消息接管与课堂信息分发系统。

## 功能

- **消息接入**：通过 OneBot 接收班级 QQ 群消息与文件事件；
- **自动分类**：识别通知 / 作业，作业进一步识别学科（关键词规则 → 本地 ONNX 模型 → 云端 LLM 三级链，可选降级）；
- **桌面悬浮窗**：通知与作业分组展示，支持已读状态、低置信作业人工确认；
- **文件归档**：课堂文件按 `归档目录/学科/日期` 自动归档，MD5 去重；
- **重试与容错**：下载 / 识别 / 写入失败自动进重试队列退避重试；
- **设置页**：连接、分类、悬浮窗、文件、维护五组设置，支持首次启动引导。

## 使用

1. 在 ClassIsland 设置 → 插件 中启用 CyberTechRep；
2. 首次启动会弹出引导窗，按提示填写 OneBot 连接配置；
3. 在维护设置页可重新打开引导、查看排错信息与重试队列。
